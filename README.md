## 💡 The Problem Space: Ending Forced Masking

For millions of autistic and neurodivergent individuals, high-stakes conversations—such as requesting workplace sensory accommodations, setting boundaries with roommates, or navigating annual performance reviews—carry intense anxiety. Traditional social skills software forces neurodivergent people to **mask**: suppressing authentic traits to mimic neurotypical conventions at grave psychological cost and chronic autistic burnout.

**Say It First** re-architects the communication sandbox into a **bilateral translation engine**:
- **Translates Pragmatic Subtext**: Clarifies what conversational partners mean beneath indirect language and unspoken social subtext.
- **Bridges Intent vs. Impact**: Shows *"What you meant"* alongside *"How it might land"* with compassionate, neutral framing (*"May..."* and *"Might..."*).
- **Empowers Non-Masking Self-Advocacy**: Synthesizes clinically grounded **DBT DEAR MAN** scripts that achieve accommodation needs without compromising personal boundaries.
- **Zero Radars or Clinical Judgment**: Replaces anxiety-inducing emotion meters and clinical scores with a calm, supportive, co-regulating practice environment.

## 📐 Mathematical Affect Engine

### Discrete-Time Exponential Damping
Partner emotional state evolves smoothly over time in Mehrabian-Russell 3D Valence-Arousal-Dominance space, preventing abrupt visual or tone snapping:

$$\mathbf{E}(t+1) = \lambda \cdot \mathbf{E}(t) + (1 - \lambda) \cdot \Delta \mathbf{E}_{\text{input}}$$

Where:
- $\mathbf{E}(t) = [V, A, D]^T$ is the current emotional coordinate vector, bounded within $[-1.0, 1.0]^3$.
- $\Delta \mathbf{E}_{\text{input}}$ is the turn perturbation generated by structured LLM reasoning.
- $\lambda = 0.65$ (adaptable peers) or $\lambda = 0.85$ (stressed supervisors).

### Tension Index & 3-Tier Safety Gate
The Tension Index ($T$) quantifies conversational stress in real time:

$$T = \left(\frac{A - V + 2.0}{4.0}\right) \times 10.0 \in [0.0, 10.0]$$

| Tension Score | Safety Tier | System Action |
| :---: | :---: | :--- |
| **$T < 7.0$** | **Tier 1: Normal Simulation** | Standard dialogue progression and subtle partner state shifts. |
| **$7.0 \le T < 9.0$** | **Tier 2: Impact Notice** | Emits gentle guidance notice: *"Partner may feel defensive or time-pressured."* |
| **$T \ge 9.0$** | **Tier 3: The Curtain Drop** | Intercept modal halts simulation and guides a 4-count visual box-breathing co-regulation reset. |

## 🚀 Quick Start

### 1. Prerequisites
- **Node.js**: `v18.x` or `v20.x`
- **npm**: `v9.x`+

### 2. Installation
```bash
git clone https://github.com/aryadevkota/say-it-first.git
cd say-it-first
npm install
```

### 3. Environment Configuration
Create `.env.local` in the project root:
```bash
cp .env.example .env.local
```

Configure your environment variables:
| Variable | Required | Description |
| :--- | :---: | :--- |
| `GEMINI_API_KEY` | **Yes** | Powers generative dialogue, subtext translation, and report generation ([Google AI Studio](https://aistudio.google.com/app/apikey)). |
| `ANAM_API_KEY` | **Yes** | Powers the real-time WebRTC live video avatar stream ([Anam AI](https://lab.anam.ai)). |
| `ELEVENLABS_API_KEY` | **Yes** | Powers Conversational AI Agent voice audio and synthesis ([ElevenLabs](https://elevenlabs.io)). |
| `ELEVENLABS_AGENT_ID` | Optional | Custom ElevenLabs Conversational AI Agent ID (falls back to default agent). |

> **Live Video Avatar Integration:**
> - **Security**: `ANAM_API_KEY` and `ELEVENLABS_API_KEY` remain strictly server-side. The client requests a short-lived ephemeral session token via `POST /api/v1/avatar/session`.
> - **Fail-Fast Diagnostics**: If keys are not configured, the API safely returns a descriptive 503 error envelope, and the UI gracefully offers text-mode practice.

### 4. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔒 Security, Privacy & Accessibility Guarantees

- **0 kbps Cloud Audio Uploads for DSP**: Acoustic prosody (WPM, RMS volume, F0 pitch autocorrelation) is computed purely in the browser via Web Audio API. Raw microphone audio never leaves your device for feature analysis.
- **Ephemeral Session State**: Conversation timeline DAGs are maintained purely in-memory (`InMemorySessionRepo`). Sensitive accommodations and private boundary disclosures are never persisted to databases or cloud storage.
- **Server-Kept Credentials**: Anam AI and ElevenLabs API keys are held strictly in server-side runtime memory. Clients only receive short-lived, single-session ephemeral tokens.
- **WCAG 2.1 AAA Accessibility**: High-contrast typography, screen-reader friendly ARIA landmarks, keyboard-navigable controls, and reduced-motion compliance.

## 📜 Architectural Decision Records (ADRs)

| ADR | Decision | Rationale |
| :---: | :--- | :--- |
| **ADR-001** | Hexagonal Ports and Adapters | Decouples browser audio DSP, LLM reasoning, and WebRTC streaming, guaranteeing 100% test coverage of domain logic. |
| **ADR-002** | In-Memory Ephemeral DAG | Guarantees instant timeline branching, non-destructive attempt resets, and zero cloud persistence of personal disclosures. |
| **ADR-003** | Client-Side Web Audio DSP | Zero server bandwidth consumption for acoustic pitch and cadence extraction; eliminates audio privacy risks. |
| **ADR-004** | Anam Real-Time WebRTC Video & ElevenLabs Agent | Delivers photorealistic conversational partner video with synchronized lip-sync and voice over a single WebRTC stream without client-side PCM noise. |
| **ADR-005** | Gemini 1.5 Flash Structured JSON Inference | Enforces strict Zod schema validation on all LLM responses with p95 latency under 1400ms for seamless turn pacing. |
